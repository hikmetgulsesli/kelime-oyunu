# PRD: kelime-oyunu

## 1. Projekt Überblick

**Projektname:** kelime-oyunu
**Projekttyp:** Tek oyuncu, tarayıcı tabanlı kelime tahmin oyunu (Wordle benzeri)
**Plattform:** Web (SPA)
**Kernfunktionalität:** Günlük 5 harfli Türkçe kelime tahmini, 6 deneme hakkı, renkli geri bildirim sistemi
**Zielgruppe:** Türkçe konuşan günlük kullanıcılar, kelime oyunu meraklıları

---

## 2. Funktionale Anforderungen

### 2.1 Kernspiel

- **Kelime uzunluğu:** 5 harf (sabit)
- **Günlük kelime:** Her gün UTC timezone'a göre yeni kelime, 00:00'da sıfırlanır
- **Tahmin hakkı:** 6 deneme
- **Geri bildirim:** Her harf için renk kodu
  - 🟩 **Yeşil:** Doğru harf, doğru pozisyon
  - 🟨 **Sarı:** Doğru harf, yanlış pozisyon
  - ⬜ **Gri:** Harf kelimede yok
- **Türkçe karakter desteği:** ç, ş, ğ, ü, ö, ı, Ç, Ş, Ğ, Ü, Ö, İ

### 2.2 Oyun Durumları (State Machine)

```
IDLE → PLAYING → (WIN | LOSE) → IDLE (next day)
```

- **IDLE:** Oyun başlamadan önce, enter tuşu ile başlar
- **PLAYING:** Aktif tahmin aşaması
- **WIN:** Doğru kelime bulundu, zafer ekranı
- **LOSE:** 6 tahmin hakkı bitti, kelime açıklanır

### 2.3 Giriş Yöntemi

- **Sanal klavye:** Ekranın altında dokunmatik/click klavye
- **Fiziksel klavye desteği:** Bilgisayarda A-Z tuşları, Enter, Backspace
- **Klavye durumu:** Kullanılan harfler renklenir (yeşil/sarı/gri)

### 2.4 İstatistikler

- Toplam oynanan oyun sayısı
- Kazanma oranı (%)
- Mevcut seri (ardışık kazanma)
- En uzun seri
- Tahmin dağılımı (1-6 deneme arasında kazanma yüzdesi)
- Günlük tahmin dağılımı grafikleri

### 2.5 Persistence (LocalStorage)

- Oyuncunun tahminleri ve sonuçları localStorage'da saklanır
- Günlük kelime seed'i: `YYYY-MM-DD` tarihinden türetilir (deterministik)
- İstatistikler localStorage'da kalıcı

## 3. Teknik Gereksinimler

### 3.1 Stack

- **Framework:** React 18+ with Vite
- **Styling:** Tailwind CSS
- **State yönetimi:** React useState/useReducer (basit oyun, Redux gereksiz)
- **Build tool:** Vite
- **Package manager:** npm

### 3.3 Kelime Listesi

- Minimum 2000 adet 5 harfli Türkçe kelime
- `validGuesses` (tahmin edilebilir) ve `targetWords` (günlük hedef) ayrımı olabilir
- Kelime listesi: `src/data/validWords.ts` veya JSON dosyası olarak

### 3.4 window.game State Exposure

Oyun durumu global olarak erişilebilir olmalı:

```typescript
declare global {
  interface Window {
    game: {
      state: GameState;
      reset: () => void;
      submitGuess: (word: string) => GuessResult | null;
      getStatistics: () => Statistics;
    };
  }
}
```
